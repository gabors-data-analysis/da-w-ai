# Starter skills

Short skills for the course [Friendly Introduction to Agentic AI for Social Scientists](https://gabors-data-analysis.com/ai-course/friendly-agentic-ai-intro/).

A skill is a recipe for one type of task. Each one is a folder with a `SKILL.md` file:
a short header (name and description), then the instructions in plain language.

| Skill | What it does | Used in |
|---|---|---|
| [read-pdf](read-pdf/SKILL.md) | Reads a PDF by extracting its text first, with page numbers | Part 2 |
| [decision-log](decision-log/SKILL.md) | Logs analytical choices in `DECISIONS.md` | Part 2 |
| [new-project](new-project/SKILL.md) | Sets up a project folder, a README and a status note | Assignment |
| [blindspot](blindspot/SKILL.md) | A fresh look at results before they are interpreted | Assignment |
| [referee](referee/SKILL.md) | Reruns a finished project and files a referee report | Assignment |
| [ref-check](ref-check/SKILL.md) | Checks that every reference exists and is correct | Assignment |
| [paper-check](paper-check/SKILL.md) | Finds where a draft contradicts itself or its exhibits | Assignment |
| [deck](deck/SKILL.md) | Turns a paper into a slide deck | Assignment |

## How to use them

Save a skill's folder under `.claude/skills/` in your project folder, and start a new
session. Then type `/` and its name, or just describe the task.

The skills are short on purpose. Read each one before you use it, and then change it:
every skill ends with ideas under *Develop it further*.

## Where they come from

`new-project`, `blindspot`, `referee`, `ref-check` and `deck` are short adaptations of
skills in Scott Cunningham's [MixtapeTools](https://github.com/scunning1975/MixtapeTools).
The fuller originals are there. The others are by Gábor Békés.
