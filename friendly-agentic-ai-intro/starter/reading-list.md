# Reading list: do big events change when babies are born?

Six papers for Part 2 of the Friendly Introduction to Agentic AI.
Download each from its **PDF link**. If that fails, use the **backup copy**
(only for papers whose licence allows sharing). Save each as the file name given.

- DOI: https://doi.org/10.1007/s10680-021-09576-2
- PDF link: https://link.springer.com/content/pdf/10.1007/s10680-021-09576-2.pdf
